# 李想个人影像作品集 / LI XIANG PORTFOLIO

面向实习申请、院校申请与合作沟通的中英双语个人网站。首屏匿名、作品优先；观众通过互动影像封面进入作品总览，再继续浏览精选项目、个人介绍、专业技能、社交主页与联系方式。

## 当前内容

- 6 个可公开播放项目：雨兽、静默防线、修面、陶骨、喜旺 × 济南文旅、默默的怀抱。
- 互动首屏：鼠标拖尾、圆形影像窗口、6 项自动轮播与手动切换；每项停留 8 秒。
- 作品总览：6 层媒体框架、自动播放、横条按钮和灰色候选画面均可手动切换；滚动时依次进入两行开放式吸顶文字、旋转扩展影像框与上下拉开、横向错位的拆分式动态标题。
- 精选项目：作品展示框按左右错层方向随滚动进入，移动端降低旋转与位移强度，并提供完整的减少动态效果回退。
- 精选项目：展示作品类型、真实职责和可打开的视频项目档案。
- 个人介绍：教育经历、工作方法、3 项工作方向、个人计划和重新编排的自我评价。
- 专业技能：6 个能力模块与 Claude、DaVinci Resolve、Codex、ChatGPT、Gemini、Kling AI、即梦 AI、Lovart、Suno 工具墙。
- 社交主页：不嵌入平台截图；以创作现场照片和重新设计的小红书、抖音、X 账号卡片呈现。
- 联系方式：邮箱、微信复制按钮和社交主页入口。
- 桌面端与移动端响应式布局、键盘可访问控件、项目弹窗和滚动定位。

## 本地开发

```powershell
pnpm install
pnpm run dev
```

生产构建与完整性检查：

```powershell
pnpm run test
pnpm run build
pnpm run preview
```

Sites 公网发布构建：

```powershell
pnpm run build:sites
```

生产发布包包含 SPA 回退、Worker 入口与移动端媒体优化。
